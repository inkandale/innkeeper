# Rules Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add saved searches and rules that keep cards archived or collected as their search says, order enrich instances by cost so cheap checks archive junk before expensive models see it, and drop the vectors of archived cards.

**Architecture:** Saved searches and rules are library tables (`saved_search`, `rule`, `rule_library`, `collection_card.rule_id`). A rule's filter reads instance-less enrichment terms from `Query.Browsable`, which browse sections adds; this plan gets it from a new `libsettings.Settings.Browsable`, built on browse sections' `BrowseKeys`. The existing hide job (`library.hide`) applies every rule that covers its library, sharing one archived list with duplicates, and the API reruns it wherever a rule or saved search changes. The enrich runner asks a `Gate`, implemented in `libsettings`, which cards must wait for a cheaper instance that an archive rule reads, and applies the rules to each batch an instance answers. A trigger created with `card_embedding` deletes a card's vectors when it is archived.

**Tech Stack:** Go (Huma, pgx v5, BurntSushi/toml), PostgreSQL 18 with pgvector, React 19 and TypeScript (TanStack Query, openapi-fetch, Vitest, Testing Library).

Spec: [`docs/superpowers/specs/2026-11-06-rules-design.md`](../specs/2026-11-06-rules-design.md). It builds on [Browse sections](../specs/2026-11-06-browse-sections-design.md), which lands first and isn't planned here.

## Decisions

Where the spec is wrong against the code, silent, or ambiguous, the plan takes the simplest reading that keeps the spec's intent:

| Topic | Decision |
|---|---|
| Actions | Archive and collect. The tag action is gone: there is no `tag` or `card_tag` table (migration 0021 dropped them), and tagging by rule would revise every card it touched. A saved search may still filter by tag. |
| A rule's action | `PUT /rules/{id}` refuses a change of action or collection, so a rule never leaves memberships it can no longer find. Make a new rule instead. |
| `saved_search.instance_id` | No foreign key. Backups keep saved searches and rules with the library (assets) and instances with config; a foreign key across the two would break a restore of either alone, which is why `enrichment.instance_id` has none either. The instance delete handler deletes the instance's saved searches. |
| `rule.saved_search_id` | `ON DELETE CASCADE`, so deleting an instance takes its searches' rules with them. The API still refuses to delete a saved search with rules (409, naming them). Deleting an instance undoes its rules the same way deleting a rule does. |
| Backups | `saved_search`, `rule`, and `rule_library` join the assets backup. All new foreign keys are `DEFERRABLE INITIALLY IMMEDIATE`, as restore defers constraints. |
| `archived_reason` | Its CHECK allows only `low_score` and `duplicate`. The rules migration widens it to `duplicate` or `rule:<id>`. The API's `archived_reason` field loses its `enum` for a `pattern`. |
| Duplicate vs. rule reason | The archived list starts with the duplicates, so a card that is both keeps `duplicate`. Among rules, the lowest ID wins. |
| Rule matches | A rule's search matches archived cards too, through a new `Query.IncludeArchived` (not in JSON). |
| When the hide job runs | `HidePayload`'s "nothing to hide" now also checks for rule work in the library: a covering rule, a membership a rule added there, or a card archived by a rule. Rule and saved-search changes call a new `RecheckHide`, which queues the job even when nothing is hidden yet, so a narrowed or disabled rule's cards come back. |
| Gates | An instance gates only while `enrich_on_change` is on for it. A gate that never runs by itself would hold cards forever, so one with it off is ignored. |
| After a batch | The spec's "an enrich batch saves values: only the cards in the batch" applies both actions, not only archive. After any batch from an instance that an enabled rule reads, the runner applies every rule covering the batch's libraries to just those cards. It doesn't recompute duplicates: it keeps cards already archived as duplicates. It queues the costlier on-change instances only when the instance is a gate. |
| Manual runs | The enrich payload gains `wait`, set by the sweep, by on-change runs, and by the runs a gate queues. A manual run never sets it. |
| Who waited | After a gate's batch, the runner queues every enabled, usable, costlier instance with `enrich_on_change` on. One that never waited skips the cards it already scored. |
| "Stores vectors" | An instance stores vectors once it has a row in `card_embedding`. Declaring a vector key isn't enough: the fake plugin and plugins with vectors switched off in config declare one and write none, and would be re-sent every card each hour. |
| Vectors on archive | A trigger on `card.archived_at`, created by `db.EnableVectors` beside the table, deletes the card's vectors. It covers every archive path: the owner's, the hide job's, and any added later. `EnableVectors` also indexes `card_embedding (card_id)`, since the primary key leads with `instance_id`. |
| Backfill | The migration deletes archived cards' vectors only when `card_embedding` exists, since `EnableVectors` creates it after migrations. |
| Opening a saved search | The Cards page takes `?saved=<id>`, ANDs that saved search's filter with the page's own terms, and shows it as a chip. A saved filter doesn't round-trip into sidebar terms: plugin searches use `missing = false`, which no term expresses. Editing a saved search's filter from the grid means narrowing it and choosing Update. |
| Search text | Saved searches hold a filter and a sort, as the spec's table says. Save search notes that text isn't saved. |
| Plugin searches | The manifest's `[searches.<id>]` takes `name` and `filter` only; the spec's table needs no sort. A filter may use only `and`, `or`, `not`, `enrichment`, `gte`, `lte`, `missing`, and `is`, so the core's install can't fail on one. Both instance-creation paths (`CreateInstance` and `EnsureSingletons`) create them in the instance's transaction. A plugin update doesn't add searches to existing instances. |
| Name collisions | `Junk`, then `Junk (<instance label>)`, then `Junk (<label> <instance id>)`. The label is the instance's name, or the plugin's title: "Junk (Card lint)", not "Junk (card-lint)". |
| `enrich_cost` for `ai` | The `ai` plugin has no `enrich` capability, and `enrich_cost` needs it, so `ai` gets none. |
| Protocol version | `enrich_cost` and `[searches]` ship in one protocol minor, one row in `docs/protocol.md`. |
| Preview paging | `POST /rules/preview` takes a `page`; every list in the response is that page of 24. |
| Merged keys | Browse sections keeps `Query.Scorers` for the grid score and adds `Query.Browsable map[string][]library.Scorer`, which instance-less terms read; its `withScores` builds that map from `libsettings.Settings.BrowseKeys`, keeping the keys with `Instance == 0`. Task 3 moves that loop into `Settings.Browsable`, which `withScores`, saved-search checks and counts, the hide payload, preview, and the gate all call. `ReadInstances` reads the map to find which instances a term reads. |
| Non-English | card-lint's search excludes `Unknown`, its value for a card too short or mixed to tell, as well as English. |

```sql
    sort text NOT NULL DEFAULT '',

    created_at timestamptz NOT NULL DEFAULT now()

CREATE INDEX ON saved_search (instance_id) WHERE instance_id IS NOT NULL;
```

```go
package library

import (
	"context"
	"fmt"
	"time"

	"github.com/jackc/pgx/v5"

	"github.com/inkandale/innkeeper/internal/db"
)

// SavedSearch is a named filter the owner opens to browse, and rules act on.
type SavedSearch struct {
	ID     int64  `json:"id"`
	Name   string `json:"name"`
	Filter Filter `json:"filter"`
	Sort   string `json:"sort" doc:"The sort to open it with, as search takes it; rules ignore it."`
	// InstanceID is the plugin instance that shipped it.
	InstanceID *int64    `json:"instance_id,omitempty" doc:"The plugin instance that shipped it. Deleting the instance deletes it."`
	CreatedAt  time.Time `json:"created_at"`
}

// CheckFilter reports whether search accepts f, with browsable as
// Query.Browsable for the enrichment terms that name no instance.
func CheckFilter(f Filter, browsable map[string][]Scorer) error {
	_, _, _, err := compile(Card, Query{Filter: &f, Browsable: browsable})
	return err
}

const savedSearchCols = `id, name, filter, sort, instance_id, created_at`

func scanSavedSearch(row pgx.Row) (SavedSearch, error) {
	var s SavedSearch
	err := row.Scan(&s.ID, &s.Name, &s.Filter, &s.Sort, &s.InstanceID, &s.CreatedAt)
	return s, err
}

func savedSearchErr(err error) error {
	switch {
	case db.IsCode(err, db.UniqueViolation):
		return ErrNameTaken
	case db.IsCode(err, db.CheckViolation):
		return fmt.Errorf("%w: a saved search needs a name without spaces around it", ErrInvalid)
	}
	return mapErr(err)
}

// CreateSavedSearch saves a search the owner made.
func (l *Library) CreateSavedSearch(ctx context.Context, name string, f Filter, sort string) (SavedSearch, error) {
	s, err := scanSavedSearch(l.pool.QueryRow(ctx, `INSERT INTO saved_search (name, filter, sort) VALUES ($1, $2, $3)
		RETURNING `+savedSearchCols, name, f, sort))
	return s, savedSearchErr(err)
}

// UpdateSavedSearch changes a saved search. Nil leaves a field as it is.
func (l *Library) UpdateSavedSearch(ctx context.Context, id int64, name *string, f *Filter, sort *string) (SavedSearch, error) {
	s, err := scanSavedSearch(l.pool.QueryRow(ctx, `UPDATE saved_search
		SET name = coalesce($2, name), filter = coalesce($3, filter), sort = coalesce($4, sort)
		WHERE id = $1 RETURNING `+savedSearchCols, id, name, f, sort))
	return s, savedSearchErr(err)
}

// DeleteSavedSearch deletes a saved search and the rules on it.
func (l *Library) DeleteSavedSearch(ctx context.Context, id int64) error {
	tag, err := l.pool.Exec(ctx, `DELETE FROM saved_search WHERE id = $1`, id)
	if err != nil {
		return err
	}
	if tag.RowsAffected() == 0 {
		return ErrNotFound
	}
	return nil
}

// DeleteInstanceSearches deletes the saved searches instance shipped, and the rules on them.
func (l *Library) DeleteInstanceSearches(ctx context.Context, instance int64) error {
	_, err := l.pool.Exec(ctx, `DELETE FROM saved_search WHERE instance_id = $1`, instance)
	return err
}

// GetSavedSearch returns one saved search.
func (l *Library) GetSavedSearch(ctx context.Context, id int64) (SavedSearch, error) {
	s, err := scanSavedSearch(l.pool.QueryRow(ctx, `SELECT `+savedSearchCols+` FROM saved_search WHERE id = $1`, id))
	return s, mapErr(err)
}

// SavedSearches returns every saved search, by name.
func (l *Library) SavedSearches(ctx context.Context) ([]SavedSearch, error) {
	rows, err := l.pool.Query(ctx, `SELECT `+savedSearchCols+` FROM saved_search ORDER BY lower(name), id`)
	if err != nil {
		return nil, err
	}
	return pgx.CollectRows(rows, func(row pgx.CollectableRow) (SavedSearch, error) { return scanSavedSearch(row) })
}
```

- [ ] **Step 3: Give the merged keys one home**

Browse sections' `withScores` builds `Query.Browsable` from `BrowseKeys` inline. Saved searches, the hide job, preview, and the gate need the same map, so move the loop into `internal/libsettings/libsettings.go`, after `BrowseKeys`:

```go
// Browsable is Query.Browsable: each merged browsable key's scorers,
// highest priority first. A key declared with two types doesn't merge, so
// it isn't here, and a term naming it without an instance is refused.
func (s *Settings) Browsable(ctx context.Context) (map[string][]library.Scorer, error) {
	keys, err := s.BrowseKeys(ctx)
	if err != nil {
		return nil, err
	}
	out := map[string][]library.Scorer{}
	for _, k := range keys {
		if k.Instance == 0 {
			out[k.Key] = k.Scorers
		}
	}
	return out, nil
}
```

In `internal/api/enrichments.go`, `withScores` becomes:

```go
// withScores sets q's scorers and merged browsable keys, if q may read them.
func (s *Server) withScores(ctx context.Context, q *library.Query) error {
	if !q.UsesScore() {
		return nil
	}
	var err error
	if q.Scorers, err = s.libSettings().Scorers(ctx); err != nil {
		return err
	}
	q.Browsable, err = s.libSettings().Browsable(ctx)
	return err
}
```

```go
// savedSearchItems adds each search's match count in lib.
func (s *Server) savedSearchItems(ctx context.Context, lib int64, searches []library.SavedSearch) ([]savedSearchItem, error) {
	browsable, err := s.libSettings().Browsable(ctx)
	if err != nil {
		return nil, err
	}
	out := make([]savedSearchItem, len(searches))
	for i, ss := range searches {
		out[i].SavedSearch = ss
		n, err := s.Lib.CountMatches(ctx, library.Card, library.Query{Library: lib, Filter: &ss.Filter, Browsable: browsable})
		switch {
		case errors.Is(err, library.ErrInvalid):
		case err != nil:
			return nil, err
		default:
			out[i].Cards = &n
		}
	}
	return out, nil
}
```

```go
// validate reports each problem with search id, whose terms must name keys.
func (s Search) validate(id string, keys map[string]Enrichment) []error {
	var errs []error
	if !keyPattern.MatchString(id) {
		errs = append(errs, fmt.Errorf("search %q must match %s", id, keyPattern))
	}
	if strings.TrimSpace(s.Name) == "" || s.Name != strings.TrimSpace(s.Name) {
		errs = append(errs, fmt.Errorf("search %q: name is required, without spaces around it", id))
	}
	if len(s.Filter) == 0 {
		return append(errs, fmt.Errorf("search %q: filter is required", id))
	}
	// Through JSON, so arrays of tables read as []any whatever the decoder made of them.
	raw, err := json.Marshal(s.Filter)
	var filter any
	if err == nil {
		err = json.Unmarshal(raw, &filter)
	}
	if err != nil {
		return append(errs, fmt.Errorf("search %q: filter: %w", id, err))
	}
	var walk func(v any)
	walk = func(v any) {
		switch t := v.(type) {
		case []any:
			for _, x := range t {
				walk(x)
			}
		case map[string]any:
			for _, k := range slices.Sorted(maps.Keys(t)) {
				switch {
				case k == "instance":
					errs = append(errs, fmt.Errorf("search %q: a term names an instance; the core fills in the new instance", id))
				case !slices.Contains(searchTerms, k):
					errs = append(errs, fmt.Errorf("search %q: filter term %q is not one of %v", id, k, searchTerms))
				}
			}
			if key, ok := t["enrichment"].(string); ok {
				if _, declared := keys[key]; !declared {
					errs = append(errs, fmt.Errorf("search %q: enrichment %q is not one of the plugin's keys", id, key))
				}
			}
			for _, k := range []string{"and", "or", "not"} {
				if x, ok := t[k]; ok {
					walk(x)
				}
			}
		default:
			errs = append(errs, fmt.Errorf("search %q: each filter term must be a table", id))
		}
	}
	walk(filter)
	return errs
}
```

```go
// createSearches saves the searches m ships, each enrichment term reading
// instance id. A name already taken gets the instance's label appended.
func createSearches(ctx context.Context, tx pgx.Tx, id int64, label string, m *protocol.Manifest) error {
	for _, key := range slices.Sorted(maps.Keys(m.Searches)) {
		s := m.Searches[key]
		filter, err := withInstance(s.Filter, id)
		if err != nil {
			return fmt.Errorf("search %q: %w", key, err)
		}
		names := []string{s.Name, fmt.Sprintf("%s (%s)", s.Name, label), fmt.Sprintf("%s (%s %d)", s.Name, label, id)}
		saved := false
		for _, name := range names {
			tag, err := tx.Exec(ctx, `INSERT INTO saved_search (name, filter, instance_id) VALUES ($1, $2, $3)
				ON CONFLICT (name) DO NOTHING`, name, filter, id)
			if err != nil {
				return fmt.Errorf("save search %q: %w", key, err)
			}
			if saved = tag.RowsAffected() == 1; saved {
				break
			}
		}
		if !saved {
			return fmt.Errorf("%w: search %q: saved searches %q already exist", ErrNameTaken, key, names)
		}
	}
	return nil
}

// withInstance is filter as JSON with instance id on every enrichment term.
func withInstance(filter map[string]any, id int64) ([]byte, error) {
	raw, err := json.Marshal(filter)
	if err != nil {
		return nil, err
	}
	var v any
	if err := json.Unmarshal(raw, &v); err != nil {
		return nil, err
	}
	var walk func(v any)
	walk = func(v any) {
		switch t := v.(type) {
		case []any:
			for _, x := range t {
				walk(x)
			}
		case map[string]any:
			if _, ok := t["enrichment"]; ok {
				t["instance"] = id
			}
			for _, x := range t {
				walk(x)
			}
		}
	}
	walk(v)
	return json.Marshal(v)
}
```

```go
package library

import (
	"context"
	"errors"
	"fmt"
	"slices"
	"strconv"

	"github.com/jackc/pgx/v5"

	"github.com/inkandale/innkeeper/internal/db"
)

// Rule actions.
const (
	RuleArchive = "archive"
	RuleCollect = "collect"
)

// RuleSpec is a rule as the owner writes it.
type RuleSpec struct {
	Name          string  `json:"name" minLength:"1"`
	SavedSearchID int64   `json:"saved_search_id"`
	Action        string  `json:"action" enum:"archive,collect" doc:"Can't change once the rule exists."`
	CollectionID  *int64  `json:"collection_id,omitempty" doc:"For collect: the collection matching cards are kept in. The rule must cover that collection's library alone. Can't change once the rule exists."`
	AllLibraries  bool    `json:"all_libraries" doc:"Covers every library, including ones made later; otherwise only libraries."`
	Libraries     []int64 `json:"libraries,omitempty" doc:"With all_libraries false: the libraries it covers."`
	Enabled       bool    `json:"enabled" doc:"A new rule starts disabled."`
}

// Rule is a saved search with an action the hide job keeps applied.
type Rule struct {
	ID int64 `json:"id"`
	RuleSpec
	SavedSearch string `json:"saved_search" doc:"Its saved search's name."`
	// Filter is its saved search's.
	Filter Filter `json:"-"`
}

// Covers reports whether r applies in library.
func (r Rule) Covers(library int64) bool {
	return r.Enabled && (r.AllLibraries || slices.Contains(r.Libraries, library))
}

// Reason is the archived_reason of the cards an archive rule archives.
func (r Rule) Reason() string { return "rule:" + strconv.FormatInt(r.ID, 10) }

// CheckRuleSpec refuses a spec whose action and collection don't go
// together, and a collect rule whose scope isn't its collection's library.
func (l *Library) CheckRuleSpec(ctx context.Context, spec RuleSpec) error {
	switch {
	case !slices.Contains([]string{RuleArchive, RuleCollect}, spec.Action):
		return fmt.Errorf("%w: a rule's action is archive or collect", ErrInvalid)
	case (spec.Action == RuleCollect) != (spec.CollectionID != nil):
		return fmt.Errorf("%w: a collect rule needs a collection, and only a collect rule takes one", ErrInvalid)
	case spec.Action != RuleCollect:
		return nil
	}
	var lib int64
	err := l.pool.QueryRow(ctx, `SELECT library_id FROM collection WHERE id = $1`, *spec.CollectionID).Scan(&lib)
	if errors.Is(err, pgx.ErrNoRows) {
		return fmt.Errorf("%w: collection %d doesn't exist", ErrInvalid, *spec.CollectionID)
	}
	if err != nil {
		return err
	}
	if spec.AllLibraries || !slices.Equal(spec.Libraries, []int64{lib}) {
		return fmt.Errorf("%w: a collect rule covers its collection's library alone, library %d", ErrInvalid, lib)
	}
	return nil
}

func ruleErr(err error) error {
	switch {
	case db.IsCode(err, db.UniqueViolation):
		return ErrNameTaken
	case db.IsCode(err, db.CheckViolation):
		return fmt.Errorf("%w: a rule needs a name without spaces around it", ErrInvalid)
	case db.IsCode(err, db.ForeignKeyViolation):
		return fmt.Errorf("%w: its saved search or one of its libraries doesn't exist", ErrInvalid)
	}
	return mapErr(err)
}

// setRuleLibraries stores spec's libraries as rule id's scope.
func setRuleLibraries(ctx context.Context, tx pgx.Tx, id int64, spec RuleSpec) error {
	if _, err := tx.Exec(ctx, `DELETE FROM rule_library WHERE rule_id = $1`, id); err != nil {
		return err
	}
	if spec.AllLibraries || len(spec.Libraries) == 0 {
		return nil
	}
	_, err := tx.Exec(ctx, `INSERT INTO rule_library (rule_id, library_id) SELECT $1, unnest($2::bigint[]) ON CONFLICT DO NOTHING`,
		id, spec.Libraries)
	return err
}

// CreateRule saves a new rule, disabled whatever spec says.
func (l *Library) CreateRule(ctx context.Context, spec RuleSpec) (Rule, error) {
	if err := l.CheckRuleSpec(ctx, spec); err != nil {
		return Rule{}, err
	}
	var id int64
	err := pgx.BeginFunc(ctx, l.pool, func(tx pgx.Tx) error {
		if err := tx.QueryRow(ctx, `INSERT INTO rule (name, saved_search_id, action, collection_id, all_libraries)
			VALUES ($1, $2, $3, $4, $5) RETURNING id`,
			spec.Name, spec.SavedSearchID, spec.Action, spec.CollectionID, spec.AllLibraries).Scan(&id); err != nil {
			return err
		}
		return setRuleLibraries(ctx, tx, id, spec)
	})
	if err != nil {
		return Rule{}, ruleErr(err)
	}
	return l.GetRule(ctx, id)
}

// UpdateRule replaces rule id's spec, and returns the rule as it was and as
// it is. Its action and collection can't change, so it never loses track of
// what it did.
func (l *Library) UpdateRule(ctx context.Context, id int64, spec RuleSpec) (before, after Rule, err error) {
	if before, err = l.GetRule(ctx, id); err != nil {
		return before, after, err
	}
	if spec.Action != before.Action || !equalPtr(spec.CollectionID, before.CollectionID) {
		return before, after, fmt.Errorf("%w: a rule's action and collection can't change; make a new rule", ErrInvalid)
	}
	if err := l.CheckRuleSpec(ctx, spec); err != nil {
		return before, after, err
	}
	err = pgx.BeginFunc(ctx, l.pool, func(tx pgx.Tx) error {
		if _, err := tx.Exec(ctx, `UPDATE rule SET name = $2, saved_search_id = $3, all_libraries = $4, enabled = $5 WHERE id = $1`,
			id, spec.Name, spec.SavedSearchID, spec.AllLibraries, spec.Enabled); err != nil {
			return err
		}
		return setRuleLibraries(ctx, tx, id, spec)
	})
	if err != nil {
		return before, after, ruleErr(err)
	}
	after, err = l.GetRule(ctx, id)
	return before, after, err
}

func equalPtr[T comparable](a, b *T) bool { return a == nil && b == nil || a != nil && b != nil && *a == *b }

// DeleteRule deletes a rule and the memberships it added.
func (l *Library) DeleteRule(ctx context.Context, id int64) error {
	tag, err := l.pool.Exec(ctx, `DELETE FROM rule WHERE id = $1`, id)
	if err != nil {
		return err
	}
	if tag.RowsAffected() == 0 {
		return ErrNotFound
	}
	return nil
}

const ruleCols = `r.id, r.name, r.saved_search_id, r.action, r.collection_id, r.all_libraries,
	array(SELECT library_id FROM rule_library WHERE rule_id = r.id ORDER BY library_id), r.enabled, s.name, s.filter
	FROM rule r JOIN saved_search s ON s.id = r.saved_search_id`

func scanRule(row pgx.Row) (Rule, error) {
	var r Rule
	err := row.Scan(&r.ID, &r.Name, &r.SavedSearchID, &r.Action, &r.CollectionID, &r.AllLibraries, &r.Libraries,
		&r.Enabled, &r.SavedSearch, &r.Filter)
	return r, err
}

func (l *Library) rulesWhere(ctx context.Context, where string, args ...any) ([]Rule, error) {
	rows, err := l.pool.Query(ctx, `SELECT `+ruleCols+` WHERE `+where+` ORDER BY r.id`, args...)
	if err != nil {
		return nil, err
	}
	return pgx.CollectRows(rows, func(row pgx.CollectableRow) (Rule, error) { return scanRule(row) })
}

// GetRule returns one rule.
func (l *Library) GetRule(ctx context.Context, id int64) (Rule, error) {
	r, err := scanRule(l.pool.QueryRow(ctx, `SELECT `+ruleCols+` WHERE r.id = $1`, id))
	return r, mapErr(err)
}

// Rules returns every rule, oldest first.
func (l *Library) Rules(ctx context.Context) ([]Rule, error) { return l.rulesWhere(ctx, `TRUE`) }

// RulesOn returns the rules on saved search id.
func (l *Library) RulesOn(ctx context.Context, savedSearch int64) ([]Rule, error) {
	return l.rulesWhere(ctx, `s.id = $1`, savedSearch)
}

// RulesOfInstance returns the rules on the saved searches instance shipped.
func (l *Library) RulesOfInstance(ctx context.Context, instance int64) ([]Rule, error) {
	return l.rulesWhere(ctx, `s.instance_id = $1`, instance)
}

// RulesIn returns the rules the hide job applies in library, oldest first:
// those that cover it, and those that collected cards there before they
// stopped covering it.
func (l *Library) RulesIn(ctx context.Context, library int64) ([]Rule, error) {
	all, err := l.Rules(ctx)
	if err != nil {
		return nil, err
	}
	rows, err := l.pool.Query(ctx, `SELECT DISTINCT cc.rule_id FROM collection_card cc JOIN card c ON c.id = cc.card_id
		WHERE cc.rule_id IS NOT NULL AND c.library_id = $1`, library)
	if err != nil {
		return nil, err
	}
	applied, err := pgx.CollectRows(rows, pgx.RowTo[int64])
	if err != nil {
		return nil, err
	}
	return slices.DeleteFunc(all, func(r Rule) bool { return !r.Covers(library) && !slices.Contains(applied, r.ID) }), nil
}

// HasRuleWork reports whether the hide job has rule work in library: a rule
// to apply, or a card a rule archived there, perhaps before a move.
func (l *Library) HasRuleWork(ctx context.Context, library int64) (bool, error) {
	rules, err := l.RulesIn(ctx, library)
	if err != nil || len(rules) > 0 {
		return len(rules) > 0, err
	}
	var archived bool
	err = l.pool.QueryRow(ctx, `SELECT EXISTS (SELECT 1 FROM card WHERE library_id = $1 AND archived_reason LIKE 'rule:%')`, library).Scan(&archived)
	return archived, err
}

// RuleScope returns the libraries r names: every library for all_libraries.
func (l *Library) RuleScope(ctx context.Context, r Rule) ([]int64, error) {
	if !r.AllLibraries {
		return r.Libraries, nil
	}
	rows, err := l.pool.Query(ctx, `SELECT id FROM library ORDER BY id`)
	if err != nil {
		return nil, err
	}
	return pgx.CollectRows(rows, pgx.RowTo[int64])
}

// RuleCount is how many cards a rule has archived or collected in one library.
type RuleCount struct {
	Rule    int64 `json:"-"`
	Library int64 `json:"library"`
	Cards   int   `json:"cards"`
}

// RuleCounts returns every rule's counts, by rule and library.
func (l *Library) RuleCounts(ctx context.Context) ([]RuleCount, error) {
	rows, err := l.pool.Query(ctx, `SELECT rule_id, library_id, sum(n)::int FROM (
			SELECT substr(archived_reason, 6)::bigint AS rule_id, library_id, count(*) AS n FROM card
			WHERE archived_reason LIKE 'rule:%' GROUP BY 1, 2
			UNION ALL SELECT cc.rule_id, c.library_id, count(*) FROM collection_card cc JOIN card c ON c.id = cc.card_id
			WHERE cc.rule_id IS NOT NULL GROUP BY 1, 2) x
		GROUP BY 1, 2 ORDER BY 1, 2`)
	if err != nil {
		return nil, err
	}
	return pgx.CollectRows(rows, pgx.RowToStructByPos[RuleCount])
}
```

```go
// give back. Only cards in among are considered, unless among is nil. Cards
```

```go
package bulk

import (
	"context"
	"fmt"
	"maps"

	"github.com/inkandale/innkeeper/internal/library"

// ApplyRules applies the rules the hide job applies in libraryID to its
// cards: all of them, or only those in among unless among is nil. hidden
// is the duplicates to archive, card ID to reason. Each archive rule's
// matches join it, a card keeping the first reason it gets, so a duplicate
// stays a duplicate and the lowest rule ID wins, and SetHidden applies the
// list. browsable, as Query.Browsable, resolves enrichment terms that name no
// instance. It adds what it did to prog.
func ApplyRules(ctx context.Context, lib *library.Library, libraryID int64, browsable map[string][]library.Scorer,
	hidden map[int64]string, among []int64, prog *HideProgress) error {
	rules, err := lib.RulesIn(ctx, libraryID)
	if err != nil {
		return err
	}
	hidden = maps.Clone(hidden)
	if hidden == nil {
		hidden = map[int64]string{}
	}
	for _, r := range rules {
		var matches []int64
		if r.Covers(libraryID) {
			if matches, err = lib.RuleMatches(ctx, libraryID, r.Filter, browsable, among); err != nil {
				return fmt.Errorf("rule %q: %w", r.Name, err)
			}
		}
		if r.Action == library.RuleArchive {
			for _, id := range matches {
				if _, ok := hidden[id]; !ok {
					hidden[id] = r.Reason()
				}
			}
			continue
		}
		add, remove, err := lib.RuleChanges(ctx, r, libraryID, matches, among)
		if err != nil {
			return fmt.Errorf("rule %q: %w", r.Name, err)
		}
		if err := lib.CollectByRule(ctx, r, add, false); err != nil {
			return fmt.Errorf("rule %q: %w", r.Name, err)
		}
		if err := lib.CollectByRule(ctx, r, remove, true); err != nil {
			return fmt.Errorf("rule %q: %w", r.Name, err)
		}
		prog.Collected += len(add)
		prog.Uncollected += len(remove)
	}
	archived, unarchived, err := lib.SetHidden(ctx, libraryID, hidden, among)
	prog.Archived += archived
	prog.Unarchived += unarchived
	return err
}
```

```go
// ruleItems adds each rule's counts.
func (s *Server) ruleItems(ctx context.Context, rules []library.Rule) ([]ruleItem, error) {
	counts, err := s.Lib.RuleCounts(ctx)
	if err != nil {
		return nil, err
	}

		}

// recheckRules reruns the hide job in every library an enabled one of rules
// names, so their change is applied or undone there.
func (s *Server) recheckRules(ctx context.Context, rules ...library.Rule) error {
	var libs []int64
	for _, r := range rules {
		if !r.Enabled {
			continue
		}
		scope, err := s.Lib.RuleScope(ctx, r)
		if err != nil {
			return err
		}
		libs = append(libs, scope...)
	}
	slices.Sort(libs)
	var errs []error
	for _, lib := range slices.Compact(libs) {
		if err := s.libSettings().RecheckHide(ctx, s.Queue, lib); err != nil {
			errs = append(errs, fmt.Errorf("queue hide for library %d: %w", lib, err))
		}
	}
	return errors.Join(errs...)
}

// dropRules runs del, which deletes rules, then reruns the hide job where
// they applied, so their archived cards come back. Their memberships go with
// them.
func (s *Server) dropRules(ctx context.Context, rules []library.Rule, del func() error) error {
	if err := del(); err != nil {
		return err
	}
	return s.recheckRules(ctx, rules...)
}
```

```go
// hold drops the cards that wait on a cheaper instance from revs, when p
// waits, and returns how many it dropped.
func (rn *Runner) hold(ctx context.Context, instanceID int64, p Payload, revs *[]protocol.EnrichRevision) (int, error) {
	if !p.Wait || rn.Gate == nil || len(*revs) == 0 {
		return 0, nil
	}

	if err != nil {
		return 0, fmt.Errorf("find cards waiting on a cheaper instance: %w", err)

	n := len(*revs)
	*revs = slices.DeleteFunc(*revs, func(rev protocol.EnrichRevision) bool { return slices.Contains(held, rev.CardID) })
	return n - len(*revs), nil
}
```

```go
package libsettings

import (
	"context"
	"errors"
	"fmt"
	"maps"
	"slices"

	"github.com/inkandale/innkeeper/internal/enrich"

	"github.com/inkandale/innkeeper/internal/library"
	"github.com/inkandale/innkeeper/internal/plugins"
)

// Gate is the enrich.Gate. An instance gates a library when an enabled
// archive rule covering it reads the instance and the instance runs as cards
// change; a card there waits for each gate cheaper than the instance it's
// sent to, until the gate has a value or a failure for its head revision. An
// instance that runs only when the owner starts it gates nothing, so no card
// waits for it forever.
type Gate struct {
	Settings *Settings
	Queue    *jobs.Queue
}

// gating is what Gate reads about the enabled enrich instances and rules.
type gating struct {
	insts     []plugins.InstanceInfo
	cost      map[int64]int
	auto      map[int64]bool // runs as cards change, so it can gate
	browsable map[string][]library.Scorer
	rules     []library.Rule // enabled only
}

func (g *Gate) load(ctx context.Context) (gating, error) {
	s := g.Settings
	insts, err := s.Enrichers(ctx)
	if err != nil {
		return gating{}, err
	}
	manifests := s.reg.Manifests()
	cost, auto := map[int64]int{}, map[int64]bool{}
	for _, inst := range insts {
		if m := manifests[inst.Plugin]; m != nil {
			cost[inst.ID] = m.EnrichCost
		}
		auto[inst.ID] = inst.EnrichOnChange && inst.Usable()
	}
	browsable, err := s.Browsable(ctx)
	if err != nil {
		return gating{}, err
	}
	rules, err := s.lib.Rules(ctx)
	if err != nil {
		return gating{}, err
	}
	rules = slices.DeleteFunc(rules, func(r library.Rule) bool { return !r.Enabled })
	return gating{insts, cost, auto, browsable, rules}, nil
}

// gates returns the instances cheaper than instance that gate libraryID.
func (gt gating) gates(instance, libraryID int64) []int64 {
	own, ok := gt.cost[instance]
	if !ok {
		return nil
	}
	var out []int64
	for _, r := range gt.rules {
		if r.Action != library.RuleArchive || !r.Covers(libraryID) {
			continue
		}
		for _, id := range library.ReadInstances(r.Filter, gt.browsable) {
			if c, ok := gt.cost[id]; ok && c < own && gt.auto[id] {
				out = append(out, id)
			}
		}
	}
	slices.Sort(out)
	return slices.Compact(out)
}

// reads reports whether a rule that keep accepts reads instance.
func (gt gating) reads(instance int64, keep func(library.Rule) bool) bool {
	return slices.ContainsFunc(gt.rules, func(r library.Rule) bool {
		return keep(r) && slices.Contains(library.ReadInstances(r.Filter, gt.browsable), instance)
	})
}

// Waiting returns which of cardIDs instance must not be sent yet.
func (g *Gate) Waiting(ctx context.Context, instance int64, cardIDs []int64) ([]int64, error) {
	gt, err := g.load(ctx)
	if err != nil || len(gt.rules) == 0 {
		return nil, err
	}
	libs, err := g.Settings.lib.CardLibraries(ctx, cardIDs)
	if err != nil {
		return nil, err
	}
	byGate := map[int64][]int64{}
	for _, card := range cardIDs {
		if lib, ok := libs[card]; ok {
			for _, gate := range gt.gates(instance, lib) {
				byGate[gate] = append(byGate[gate], card)
			}
		}
	}
	var waiting []int64
	for gate, cards := range byGate {
		pending, err := g.Settings.lib.Unanswered(ctx, gate, cards)
		if err != nil {
			return nil, fmt.Errorf("find cards instance %d hasn't answered: %w", gate, err)
		}
		waiting = append(waiting, pending...)
	}
	slices.Sort(waiting)
	return slices.Compact(waiting), nil
}

// Answered applies the rules to cardIDs once instance, which an enabled rule
// reads, has answered them. When instance is a gate, it then queues the
// cards still unarchived on each costlier instance that runs as cards
// change; one that didn't wait skips the cards it already scored.
func (g *Gate) Answered(ctx context.Context, instance int64, cardIDs []int64) error {
	gt, err := g.load(ctx)
	if err != nil || !gt.reads(instance, func(library.Rule) bool { return true }) {
		return err
	}
	lib := g.Settings.lib
	libs, err := lib.CardLibraries(ctx, cardIDs)
	if err != nil {
		return err
	}
	byLib := map[int64][]int64{}
	for card, l := range libs {
		byLib[l] = append(byLib[l], card)
	}
	for _, l := range slices.Sorted(maps.Keys(byLib)) {
		among := byLib[l]
		slices.Sort(among)
		// Duplicates aren't recomputed here, so the ones already archived stay.
		dups, err := lib.ArchivedAs(ctx, among, library.ReasonDuplicate)
		if err != nil {
			return err
		}
		var prog bulk.HideProgress
		if err := bulk.ApplyRules(ctx, lib, l, gt.browsable, dups, among, &prog); err != nil {
			return fmt.Errorf("apply rules in library %d: %w", l, err)
		}
	}
	if !gt.auto[instance] || !gt.reads(instance, func(r library.Rule) bool { return r.Action == library.RuleArchive }) {
		return nil
	}
	live, err := lib.Unarchived(ctx, cardIDs)
	if err != nil || len(live) == 0 {
		return err
	}
	manifests := g.Settings.reg.Manifests()
	var errs []error
	for _, x := range gt.insts {
		if x.ID == instance || !gt.auto[x.ID] || gt.cost[x.ID] <= gt.cost[instance] {
			continue
		}
		p := enrich.Payload{CardIDs: live[:min(len(live), enrich.MaxCards(manifests[x.Plugin]))], Wait: true}
		if _, err := g.Queue.EnqueueUnlessQueued(ctx, jobs.Spec{Kind: enrich.Kind, InstanceID: &x.ID, Payload: p}); err != nil {
			errs = append(errs, fmt.Errorf("queue enrich on instance %d: %w", x.ID, err))
		}
	}
	return errors.Join(errs...)
}
```

```markdown
## Saved searches and rules

A **saved search** is a named filter. On the Cards page, filter the cards
and choose Save search; Saved searches lists them, each with how many cards
it matches in the current library. Opening one shows its cards in any
library, and filters you add narrow it. Update folds them in. A plugin can
ship saved searches over its own scores, saved when you add its instance.
See `/saved-searches`.

A **rule** is a saved search with an action that Innkeeper keeps applied in
the libraries it covers: all of them, new ones included, or a chosen list.

| Action | Keeps | Gives back |
|---|---|---|
| Archive | matching cards archived, with the rule as the reason | cards that stop matching, which the enrich sweep then scores again |
| Collect | matching cards in a collection of the one library it covers | cards it added that stop matching |

A saved search can filter on anything search can, tags included. A rule
never undoes what you did by hand: a card you archived, or a card you put in
the collection, stays. A new rule starts off.
Turning one on, or saving one that's on, shows what it would change, library
by library, and changes nothing until you confirm (`POST /rules/preview`).
The hide job then applies it, and runs again whenever a rule or its saved
search changes, and after imports and moves. A rule's action can't change;
make a new rule.

Archive rules also order enrich plugins. Each plugin has a cost, and an
instance waits on a card while a cheaper instance that an archive rule reads,
and that updates cards as they change, hasn't scored it. A free check can then archive junk before a paid model
sees it. A run you start yourself never waits.

Archiving a card, by hand, as a duplicate, or by a rule, deletes its
vectors; its scores stay. Unarchiving it gets it embedded again.
```
