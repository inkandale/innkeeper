# SOLID and DRY audit, 2026-10-13

Findings from a read-only audit of the Go core and web UI against
[AGENTS.md](../../AGENTS.md). File references are to `main` at the time of
the audit. Tick an item when its fix merges.

## 1. Card vs lorebook knowledge is spread across six places

- [x] One exported `library.Kind` (name, plural, table, revTable, fk,
      sourceTable) on `Entities`, with a lookup by name. Delete
      `library.searchKind` (`search.go:110`); search takes the kind.
- [x] `targets.kind` (`kind.go:10`) embeds it and adds only the plugin
      methods, fields, and schema.
- [x] Public methods take a kind; delete the forwarding pairs:
      `Bindings`/`LorebookBindings`, `Items`/`LorebookItems`,
      `Bind`/`BindLorebook`, `Push`/`PushLorebook`,
      `Preview`/`PreviewLorebook`, `PreviewBulkPush`/`PreviewBulkLorebookPush`,
      `EnqueuePush`/`EnqueueLorebookPush`,
      `EnqueueBulkPush`/`EnqueueBulkLorebookPush`,
      `CompareItem`/`CompareLorebookItem`, `Resolve`/`ResolveLorebook`,
      `Search`/`SearchLorebooks`, `SearchIDs`/`SearchLorebookIDs`.
- [x] Delete the API tables and ternaries that pick a wrapper:
      `syncedKind` (`api/targets.go:85`), the resolve table
      (`api/reconcile.go:131`), `kindEntities` (`api/catalogs.go:185`), and
      the pointer comparisons `ents == s.Lib.Cards` in `api/entities.go`.
- [x] Regular paths `/{plural}/search` and `/instances/{id}/{plural}`,
      keeping the old paths. Then drop the kind switches in MCP
      (`plural`, `itemPath`, `tools.go:305`, `tools.go:390`), `ink`
      (`cmd/ink/library.go:18`), and the web UI (`Cards.tsx:46`,
      `Review.tsx:218`).

## 2. Plugin calls and their errors are handled in several copies

- [x] `s.fail` hides a plugin's error text for every plugin, as
      `catalogCall` does now. Today `server.go:242` returns it to clients,
      and it can name files on the server.
- [x] `catalogCall` (`api/catalogs.go:106`) becomes the shared instance
      check plus `Registry.Call`; its error switch goes.
- [x] `auth.callPlugin` (`api/auth.go:142`) uses `Registry.Call`.
- [x] The importer (`importer.go:142-161`) uses `Registry.Call` and
      `plugins.Retryable` instead of its own copies.
- [x] One `plugins.JobErr(err)` replaces the job error switch in
      `targets/jobs.go`, `reconcile_job.go`, `resolve_job.go`, and the
      importer.

## 3. Catalog ingest is grafted onto the importer

- [ ] Replace the `ingest bool` in `importer.go` with a map from job kind
      to plugin method.
- [ ] `start-catalog-ingest` (`api/catalogs.go:295`) shares
      `start-import`'s code (`api/jobs.go:270`).
- [ ] One `library.ImportItem` used by adopt (`api/catalogs.go:348`) and
      the importer (`importer/ingest.go:30`).
- [ ] One `library.DataName(raw)` for the nine `data.name` reads.

## 4. Core code that names a plugin or site

- [ ] Source detection for chub, RisuRealm, and Character Tavern
      (`library/detect.go:26-164`) moves to a plugin. Needs a new
      capability; design it first.
- [ ] `BringInCards.tsx:80` picks importers by the `import` capability,
      and chooses file or URL input from the manifest's `formats`.
- [ ] Export formats in `card/Panel.tsx:41` and `SelectionBar.tsx:158`
      come from the codec plugins' formats.
- [ ] The recommended plugins (`settings/Plugins.tsx:13`) and wizard
      categories (`welcome/wizard.ts:9`) come from the plugin index.

## 5. "Instances with capability X" is written by hand

- [ ] `Registry.InstancesWith(ctx, caps...)` and
      `Registry.InstanceWith(ctx, id, cap)` replace about ten hand-rolled
      lookups in `api/` and `targets/sync.go`.
- [ ] `Manifest.Has(cap)` replaces inline `slices.Contains` checks.
- [ ] One `withCapability` helper in `web/src/api/client.ts` replaces four
      copies.

## 6. Web UI query and error boilerplate

- [ ] `api/queries.ts` holds the shared queries (`instances`, `plugins`,
      `collections`, `me`, `settings`), each written once.
- [ ] A `MutationCache` `onError` toast replaces 12 per-mutation copies and
      the `a.error ?? b.error` chains that show stale errors.
- [ ] A `useJob` hook; one `jobStates` list. `Job.tsx:93` is missing
      `waiting`.
- [ ] A `useModal` hook for the four dialog effects.

## 7. Functions that do too much

- [ ] Split `resolver.bind` (`targets/resolve.go:428`, 252 lines); make the
      merge a pure function with its own tests.
- [ ] Split `Service.Reconcile` (`targets/reconcile.go:391`); one
      `s.list` for the three plugin list calls.
- [ ] Move the diff renderer out of `sync/Review.tsx` and use it in
      `card/History.tsx`.

## 8. Smaller items

- [ ] `auth.go:285` calls `s.loginProviders` instead of copying it.
- [ ] Named constants for Postgres error codes (`23505`, `23503`,
      `23514`) in `internal/db`.
- [ ] `pgx.BeginFunc` for the transaction and non-transaction method pairs
      in `library`.
- [ ] One `library.WrapCard` for the three CCv3 wrappers.
- [ ] Contract checks keyed by capability (`contract.go:91`).
- [ ] `ink`: one API call helper; `cmp.Or` for `or()`.
- [ ] Unexport or delete exports used only by tests.

## Not doing

it changes the protocol, so the old methods would have to stay, and only
two kinds exist.
