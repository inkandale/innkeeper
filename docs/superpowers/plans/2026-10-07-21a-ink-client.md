# ink client Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A separate `ink` binary, downloadable for six platforms, takes over the API commands from `innkeeper`, with `--help` on every command, tables or `--json`, and shell completions.

**Architecture:** `cmd/ink` lives in the server's module and imports its API types, so a breaking API change fails to compile. Types `ink` shares with the server move to `internal/wire`, which imports no server packages, so `ink` builds for Windows; `internal/targets` keeps aliases, so server code is unchanged. Commands are hand-written with cobra, which gives `--help` and completions for bash, zsh, fish, and PowerShell. Each release attaches the binaries to its GitHub release.

**Tech Stack:** Go 1.27, `github.com/spf13/cobra`, GitHub Actions, Docker.

Ticket: INN-21. Slices:

| Plan | Delivers |
|---|---|
| 21a (this) | `ink` with today's API commands, `--json`, completions, release binaries |
| 21b | `ink login`/`logout`, profiles, keychain; the server binds OAuth grants to a resource (`/mcp` or `/api`), accepts any loopback port (RFC 8252 §7.3), and revokes tokens (RFC 7009) |
| 21c | `ink cards` and `ink lorebooks`: list, search, show, create, edit in `$EDITOR`, history, archive, export, import a file |
| 21d | `ink sync`: bindings, status, preview, push with a diff and a prompt (`--yes` skips it), adopt, bind |
| 21e | `ink instances`, `ink plugins`, `ink backups` |

Decisions recorded during planning:

- Commands land in their final namespaces now, so later slices add commands without renaming any: `ink cards export|archive|unarchive|sources`, `ink sync push|reconcile|compare|resolve|apply`. `ink import` stays top level because it serves folder importers as well as apps.
- `innkeeper resolve --suggested <job-id>` becomes its own command, `ink sync apply <job-id>`.
- `export`'s positional format becomes `--format`.
- Until 21b, `ink` reads only `INNKEEPER_URL` and `INNKEEPER_TOKEN`. Profiles arrive with login, which is what needs them.
- `internal/wire` gains types only as `ink` needs them. 21a moves the reconcile types; job and source rows stay local structs, as today.

// version is set at release with -ldflags "-X main.version=...".
var version = "dev"

func main() {
	if err := newRoot().Execute(); err != nil {
		fmt.Fprintln(os.Stderr, "ink:", err)
		os.Exit(1)
	}
}

func newRoot() *cobra.Command {
	root := &cobra.Command{
		Use:   "ink",
		Short: "Work with an Innkeeper server",
		Long: `ink calls the Innkeeper API at INNKEEPER_URL with the API token in INNKEEPER_TOKEN.
Make a token on the server with: innkeeper token create <name> [read|write|destructive]`,
		Version:      buildVersion(),
		SilenceErrors: true,
		// Usage helps with a wrong argument or flag, which cobra reports
		// before this runs; it only buries an API error.
		PersistentPreRun: func(cmd *cobra.Command, _ []string) { cmd.SilenceUsage = true },
	}
	root.PersistentFlags().Bool("json", false, "print JSON instead of tables")
	root.AddCommand(callCmd())
	return root
}

// buildVersion is the release version, or the module version for go install.
func buildVersion() string {
	if info, ok := debug.ReadBuildInfo(); ok && version == "dev" && info.Main.Version != "" && info.Main.Version != "(devel)" {
		return info.Main.Version
	}
	return version
}

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"strings"

	"github.com/spf13/cobra"
)

// jsonArg returns args[i] if it is valid JSON, or def if args has no index i.
func jsonArg(args []string, i int, def string) (json.RawMessage, error) {
	if len(args) <= i {
		return json.RawMessage(def), nil
	}
	if !json.Valid([]byte(args[i])) {
		return nil, fmt.Errorf("%q is not valid JSON", args[i])
	}
	return json.RawMessage(args[i]), nil
}

func jsonFlag(cmd *cobra.Command) bool {
	v, _ := cmd.Flags().GetBool("json")
	return v
}

// show prints an API response as it came with --json, and otherwise decodes
// it and prints it with table.
func show[T any](cmd *cobra.Command, raw []byte, table func(io.Writer, T) error) error {
	w := cmd.OutOrStdout()
	if jsonFlag(cmd) {
		_, err := fmt.Fprintln(w, strings.TrimSuffix(string(raw), "\n"))
		return err
	}
	var v T
	if err := json.Unmarshal(raw, &v); err != nil {
		return err
	}
	return table(w, v)
}

func callCmd() *cobra.Command {
	return &cobra.Command{
		Use:     "call <method> <path> [json]",
		Short:   "Make any API call and print the response",
		Long:    "Call reaches API routes that have no command of their own. The path is under /api; the API docs are at /api/docs on the server.",
		Example: "  ink call GET /jobs\n  ink call PATCH /settings '{\"theme\": \"dusk\"}'",
		Args:    cobra.RangeArgs(2, 3),
		RunE: func(cmd *cobra.Command, args []string) error {
			body, err := jsonArg(args, 2, "")
			if err != nil {
				return err
			}
			if len(body) == 0 {
				body = nil
			}
			c, err := newClient()
			if err != nil {
				return err
			}
			out, err := c.do(cmd.Context(), strings.ToUpper(args[0]), args[1], body)
			if err != nil {
				return err
			}
			_, err = fmt.Fprintln(cmd.OutOrStdout(), strings.TrimSuffix(string(out), "\n"))
			return err
		},
	}
}
```

// watchJob prints a line each time the job changes, and fails unless the job
// succeeds.
func watchJob(ctx context.Context, c *client, id string, w io.Writer) error {
	status := ""
	err := c.stream(ctx, "/jobs/"+id+"/events", func(data []byte) error {
		var j struct {
			Status   string          `json:"status"`
			Progress json.RawMessage `json:"progress"`
			Children map[string]int  `json:"children"`
			Outcomes map[string]int  `json:"outcomes"`
			Error    *string         `json:"error"`
		}
		if err := json.Unmarshal(data, &j); err != nil {
			return err
		}
		status = j.Status
		line := j.Status + " " + string(j.Progress)

for, or only the remote IDs named. A bind keeps the library's side of every hunk.`,
		Example: "  ink sync apply 41 --verdict exact\n  ink sync apply 41 brakka.png",
		Args:    cobra.MinimumNArgs(1),
		RunE: func(cmd *cobra.Command, args []string) error {
			jobID, err := parseID(args[0])
			if err != nil {
				return err
			}
			remoteIDs := args[1:]
			c, err := newClient()
			if err != nil {
				return err
			}
			ctx := cmd.Context()
			snap, err := snapshot(ctx, c, jobID)
			if err != nil {
				return err
			}
			inst := fmt.Sprint(snap.Params.InstanceID)
			var rs []wire.Resolution
			add := func(kind, itemsPath string, it wire.ReconcileItem) error {
				s := it.Suggested
				if s == nil || len(verdicts) > 0 && !slices.Contains(verdicts, it.Verdict) ||
					len(remoteIDs) > 0 && !slices.Contains(remoteIDs, it.RemoteID) {
					return nil
				}
				r := wire.Resolution{InstanceID: snap.Params.InstanceID, RemoteID: it.RemoteID, Kind: kind,
					AppHash: it.AppHash, Action: s.Action, CardID: s.CardID}
				if s.Action == "bind" {
					// The snapshot doesn't carry the card's head, so a bind reads it
					// from a comparison; the snapshot's app_hash still guards the app.
					path := "/instances/" + inst + "/" + itemsPath + "/" + url.PathEscape(it.RemoteID) + "/compare"
					q := "card_id"
					if kind == "lorebook" {
						q = "lorebook_id"
					}
					cmp, err := fetchComparison(ctx, c, fmt.Sprintf("%s?%s=%d", path, q, s.CardID))
					if err != nil {
						return fmt.Errorf("%s: %w", it.RemoteID, err)
					}
					r.BaseRevisionID, r.AcceptedHash = cmp.HeadRevisionID, cmp.AcceptedHash
				}
				rs = append(rs, r)
				return nil
			}
			for _, it := range snap.Items {
				if err := add("card", "items", it); err != nil {
					return err
				}
			}
			for _, lb := range snap.Lorebooks {
				if err := add("lorebook", "lorebook-items", lb); err != nil {
					return err
				}
			}
			if len(rs) == 0 {
				return errors.New("no suggestions match")
			}
			return startJob(cmd, "/resolutions", map[string]any{"resolutions": rs})
		},
	}
	apply.Flags().StringSliceVar(&verdicts, "verdict", nil, "only items with these verdicts: exact, likely, new")
	return apply
}

## CLI

`ink` works with a server's API from any machine. The server binary,
`innkeeper`, runs the server and the commands that need its database.

### ink

Download `ink` for your platform from the
[latest release](https://github.com/davidgibbons/innkeeper/releases/latest),
or build it:

```bash
go install github.com/davidgibbons/innkeeper/cmd/ink@latest
```

The image includes `ink` too. It reads `INNKEEPER_URL` and an API token in
`INNKEEPER_TOKEN`; make one on the server with
`innkeeper token create <name> [read|write|destructive]`.

```text
ink call <method> <path> [json]                   any API call, such as: ink call GET /jobs
ink import <instance-id> [params-json]            start an import
ink jobs [show|cancel|watch <job-id>]             list or follow jobs
ink cards export <card-id> [file] [--format f]    a card as CCv3 JSON, or a codec's format (.png means png)
ink cards archive|unarchive <query-json>          archive or unarchive the cards a search matches
ink cards sources <card-id>                       list a card's sources
ink cards sources add <card-id> <url>
ink cards sources remove <card-id> <source-id>
ink sync push <instance-id> <card-id>|<query-json> [--new-copy]
                                                  push one card, or the cards a search matches, to an app
ink sync reconcile <instance-id> [params-json]    line an app up against the library
ink sync compare <instance-id> <remote-id> [card-id]
                                                  show how an app character differs from a card
ink sync resolve <instance-id> <remote-id> bind|import|skip [card-id] [hunk=choice ...] [--default choice]
                                                  bind, import, or skip one app character
ink sync apply <reconcile-job-id> [remote-id ...] [--verdict v,...]
                                                  resolve a reconcile's items as it suggested
```

`--json` prints JSON instead of tables, and every command takes `--help`.
`ink completion bash|zsh|fish|powershell` prints a shell completion script;
`ink completion <shell> --help` says where to put it.

`cards archive` needs a query with a `filter` or `text`; to select every card,
filter on `archived`. It touches only cards not already in the target state.
The API's `POST /bulk` also tags, collects, and exports; see `/api/docs`.

`jobs watch` exits non-zero unless the job succeeds.

`sync push --new-copy` is for apps that can't update a card: pushing there
again makes another copy, so the push fails without the flag.

Exporting in a format other than `json` needs an instance of a codec plugin
that writes it. Export uses the oldest working codec instance for the format:

```bash
ink call POST /instances '{"plugin": "card-codec", "name": "Codec"}'
ink cards export 12 brakka.png
```
