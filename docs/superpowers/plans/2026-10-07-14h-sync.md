> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Sync page, the reconcile queue, the diff editor, drift review from the card and lorebook pages, and a push preview before every push.

**Architecture:** Frontend only. The API already has every endpoint: `/search` target facets for counts, `/jobs?kind=target.reconcile` for the last run, `/reconciles`, the compare and resolve routes, `/resolutions`, `/pushes`, and `push-preview`. Pure helpers in `web/src/sync/sync.ts` type the reconcile snapshot (the job's `progress`, which the schema leaves untyped) and build resolutions. Each screen is one component under `web/src/sync/`.

**Tech Stack:** React, React Router, TanStack Query, `openapi-fetch`, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-05-web-ui-design.md`, "Sync". Build order phase 7. The reconcile API (`docs/superpowers/specs/2026-10-05-reconcile-design.md`) is merged.

## Design notes

- **The diff editor is a route, not a dialog:** `/sync/:instance/:kind/:remoteId`, where `kind` is the API's path segment, `items` or `lorebook-items`. `?job=` names the reconcile whose snapshot gives the options and nested world books; `?card=` names the library card or lorebook to compare with. A full-page route works with Back and lets the card page link to a drift review, as History does.
- **Choices per hunk:** Library or App, plus Both on list hunks, the only ones the API accepts it on. Only `conflict`, `library_only`, and `app_only` hunks take a choice; `auto_*` hunks show which side merged, and fields with only `same` hunks start collapsed. The resolution sends `default: "library"` and only the choices that differ from it.
- **Apply N suggested compares each bind first.** The snapshot has no library head, and a bind needs `base_revision_id`, so each bind row gets a comparison, four at a time, as `innkeeper resolve --suggested` does. The snapshot's `app_hash` stays in the resolution, so an app item that changed since the run goes stale. Nested world books are left out and take their suggestions.
- **A `409` on resolve reloads the comparison** and clears the choices, since the hunk IDs may have changed.
- **Push preview:** one card or lorebook gets a dialog with each changed field's before and after, and pushes with the preview's `confirm`. A `409` reloads the preview. Bulk pushes keep their action panel; it now lists what the push does to each copy (new, ahead, in sync, drifted) from the target facet. Push all ahead asks again with the count.
- **Counts are cards only.** The Sync page and Push all ahead count and push cards. A card push creates the lorebooks the app lacks; updating ahead lorebooks is the Lorebooks list's bulk push.
- **Out of this plan:** `keep_in_app` choices, word-level highlights, Playwright, and links from the Sync counts to filtered card lists.

```ts
import { api, must } from "../api/client";
import type { components } from "../api/schema";

export type Comparison = components["schemas"]["Comparison"];
export type Resolution = components["schemas"]["Resolution"];
type Hunk = components["schemas"]["Hunk"];
type TargetCount = components["schemas"]["TargetCount"];

// The snapshot is a reconcile job's progress, which the schema leaves
// untyped. These match Snapshot in internal/targets/reconcile.go.
export type Option = { action: "bind" | "import" | "skip"; card_id?: number; why?: string };
export type Candidate = {
  card_id: number;
  name: string;
  reasons: Record<string, number> | null;
  differing_fields: number;
  conflicts: number;
  bound_to?: string;
};
export type Item = {
  remote_id: string;
  name: string;
  app_hash: string;
  verdict: "bound" | "exact" | "likely" | "new" | "error";
  error?: string;
  binding_id?: number;
  candidates?: Candidate[];
  options: Option[] | null;
  suggested?: Option;
  lorebooks?: Item[];
  auto_bound?: boolean;
};
export type Snapshot = {
  params: { instance_id: number };
  items: Item[] | null;
  lorebooks: Item[] | null;
  missing: number[] | null;
  unpushed: number[] | null;
  totals: Record<string, number> | null;
};

/** ItemKind is an app item's path segment in the API. */
export type ItemKind = "items" | "lorebook-items";
export type Row = { kind: ItemKind; item: Item };

/** snapshotOf is a finished reconcile's snapshot, or undefined while it runs or when a job list cut it to totals. */
export function snapshotOf(job: { status: string; progress: unknown } | undefined): Snapshot | undefined {
  const p = job?.status === "succeeded" ? job.progress : undefined;
  return p && typeof p === "object" && "params" in p ? (p as Snapshot) : undefined;
}

/** rows lists a snapshot's characters, then its world books no character links to. */
export function rows(s: Snapshot): Row[] {
  return [
    ...(s.items ?? []).map((item) => ({ kind: "items" as const, item })),
    ...(s.lorebooks ?? []).map((item) => ({ kind: "lorebook-items" as const, item })),
  ];
}

export const rowKey = (r: Row) => `${r.kind}/${r.item.remote_id}`;

export const optionKey = (o: Option) => (o.action === "bind" ? `bind:${o.card_id}` : o.action);

export function optionLabel(o: Option, candidates: Candidate[] = []): string {
  if (o.action === "import") return "Import as new";
  if (o.action === "skip") return "Skip";
  return `Bind to ${candidates.find((c) => c.card_id === o.card_id)?.name ?? "#" + o.card_id}`;
}

/** decidable hunks take the owner's choice; the others merge by their status. */
export const decidable = (h: Hunk) => h.status === "conflict" || h.status === "library_only" || h.status === "app_only";

/** resolution decides one app item. A bind carries its comparison's hashes, so the API refuses it if anything changed since. */
export function resolution(
  remoteId: string,
  appHash: string,
  action: Option["action"],
  cmp?: Comparison,
  choices: Record<string, string> = {},
): Resolution {
  if (action !== "bind") return { remote_id: remoteId, app_hash: appHash, action };
  if (!cmp) throw new Error(`compare ${remoteId} before binding it`);
  const picked = Object.fromEntries(Object.entries(choices).filter(([, c]) => c !== "library"));
  return {
    remote_id: remoteId,
    action,
    card_id: cmp.card_id,
    app_hash: cmp.app_hash,
    base_revision_id: cmp.head_revision_id,
    accepted_hash: cmp.accepted_hash,
    default: "library",
    ...(Object.keys(picked).length ? { choices: picked } : {}),
  };
}

/** bulkResolutions resolves rows as picked. The snapshot has no library head, so each bind is compared first. */
export async function bulkResolutions(
  instance: number,
  picked: Row[],
  pick: (r: Row) => Option,
  compare: (r: Row, id: number) => Promise<Comparison>,
): Promise<Resolution[]> {
  const out: Resolution[] = [];
  // ponytail: four comparisons at a time, each reading the app; batch on the server if a few hundred binds is too slow.
  for (let i = 0; i < picked.length; i += 4) {
    const batch = picked.slice(i, i + 4).map(async (r) => {
      const o = pick(r);
      const cmp = o.action === "bind" ? await compare(r, o.card_id ?? 0) : undefined;
      return {
        ...resolution(r.item.remote_id, r.item.app_hash, o.action, cmp),
        // The run's hash, so an item that changed after the owner saw it goes stale.
        app_hash: r.item.app_hash,
        instance_id: instance,
        ...(r.kind === "lorebook-items" ? { kind: "lorebook" as const } : {}),
      };
    });
    out.push(...(await Promise.all(batch)));
  }
  return out;
}

export async function compareItem(instance: number, kind: ItemKind, remoteId: string, id: number): Promise<Comparison> {
  const path = { id: instance, remote_id: remoteId };
  return kind === "items"
    ? must(await api.GET("/instances/{id}/items/{remote_id}/compare", { params: { path, query: { card_id: id } } }))
    : must(await api.GET("/instances/{id}/lorebook-items/{remote_id}/compare", { params: { path, query: { lorebook_id: id } } }));
}

export async function resolveItem(instance: number, kind: ItemKind, remoteId: string, body: Resolution) {
  const path = { id: instance, remote_id: remoteId };
  return kind === "items"
    ? must(await api.POST("/instances/{id}/items/{remote_id}/resolve", { params: { path }, body }))
    : must(await api.POST("/instances/{id}/lorebook-items/{remote_id}/resolve", { params: { path }, body }));
}

export function reviewPath(instance: number, kind: ItemKind, remoteId: string, params: Record<string, number> = {}): string {
  const q = new URLSearchParams(Object.entries(params).map(([k, v]) => [k, String(v)])).toString();
  return `/sync/${instance}/${kind}/${encodeURIComponent(remoteId)}${q ? "?" + q : ""}`;
}

export type Counts = Record<"in_sync" | "ahead" | "drifted" | "missing" | "cant_check" | "bound", number>;

/** stateCounts reads one instance's cards by status from a target facet. Drifted is remote_changed plus diverged. */
export function stateCounts(targets: TargetCount[] | null | undefined, instance: number): Counts {
  const c: Counts = { in_sync: 0, ahead: 0, drifted: 0, missing: 0, cant_check: 0, bound: 0 };
  for (const t of targets ?? []) {
    if (t.instance !== instance) continue;
    const k = t.is === "remote_changed" || t.is === "diverged" ? "drifted" : t.is;
    if (k in c && k !== "bound") c[k as keyof Counts] += t.cards;
    c.bound += t.cards;
  }
  return c;
}

/** pushSummary says what pushing total cards does to the app's copies. Unbound and missing ones become new copies. */
export function pushSummary(total: number, c: Counts): string {
  const parts: [number, string][] = [
    [total - c.bound + c.missing, "new"],
    [c.ahead, "ahead"],
    [c.in_sync, "in sync"],
    [c.cant_check, "can't check"],
    [c.drifted, "drifted (pushing overwrites their app edits)"],
  ];
  return parts
    .filter(([n]) => n > 0)
    .map(([n, s]) => `${n} ${s}`)
    .join(", ");
}
```

`web/src/sync/PushPreview.tsx`:

```tsx
import { useMutation, useQuery } from "@tanstack/react-query";
import { useLayoutEffect, useRef } from "react";
import { api, ApiError, must, route, type Kind } from "../api/client";
import { show } from "../card/draft";
import { useToast } from "../shell/Toasts";
import "./Sync.css";

/** PushPreview shows what pushing one card or lorebook changes in the app, and pushes once the owner confirms. */
export function PushPreview(props: { kind: Kind; id: number; instance: number; name: string; onClose: () => void }) {
  const { kind, id, instance, name, onClose } = props;
  const toast = useToast();
  const dialog = useRef<HTMLDialogElement>(null);
  useLayoutEffect(() => {
    const d = dialog.current;
    // jsdom has no showModal.
    if (d?.showModal) d.showModal();
    else d?.setAttribute("open", "");
    return () => d?.close?.();
  }, []);
  const preview = useQuery({
    queryKey: [kind, id, "push-preview", instance],
    // Read the app afresh each time: the confirm vouches for this exact preview.
    gcTime: 0,
    queryFn: async () =>
      must(await api.GET(route(kind, "/cards/{id}/push-preview"), { params: { path: { id }, query: { instance_id: instance } } })),
  });
  const p = preview.data;
  const push = useMutation({
    mutationFn: async () =>
      must(
        await api.POST(route(kind, "/cards/{id}/push"), {
          params: { path: { id } },
          body: { instance_id: instance, confirm: p!.confirm, ...(p!.new_copy ? { new_copy: true } : {}) },
        }),
      ),
    onSuccess: (j) => {
      toast({ text: `Job ${j.id} started`, link: { to: `/settings/jobs/${j.id}`, label: "View job" } });
      onClose();
    },
    onError: (e) => {
      const changed = e instanceof ApiError && e.status === 409;
      if (changed) void preview.refetch();
      toast({ text: changed ? "What the push sends has changed. Check the new preview." : e.message, error: true });
    },
  });

  const j = job.data;

function FieldChoices({ scope, field, choices, onChoose }: { scope: string; field: Field; choices: Choices; onChoose: (id: string, c: string) => void }) {
  const hunks = field.hunks ?? [];
  const differs = hunks.some((h) => h.status !== "same");
  const label = (h: Hunk) => {
    if (field.kind !== "entries") return "";
    const e = entryOf(h.id);
    return e.field ? `${e.entry} · ${e.field}` : e.entry;
  };
  return (
    <details className="field" open={differs}>
      <summary>
        {field.path}
        {!differs && <span className="muted"> · same</span>}

          <p key={h.id} className="hunks same">
            {show(h.library)}
          </p>
        ) : decidable(h) ? (
          <HunkChoice
            key={h.id}
            scope={scope}
            hunk={h}
            label={label(h)}
            list={field.kind === "list"}
            choice={choices[h.id] ?? "library"}
            onChoose={(c) => onChoose(h.id, c)}
          />
        ) : (
          <p key={h.id} className="hunks">

}

/** Review is the diff editor: one app item against a library card, decided hunk by hunk, with the card's world books nested. */
export function Review() {
  const params = useParams();
  const instance = Number(params.instance);
  const kind: ItemKind = params.kind === "lorebook-items" ? "lorebook-items" : "items";
  const remoteId = params.remoteId ?? "";
  const [search, setSearch] = useSearchParams();
  const jobId = Number(search.get("job")) || 0;
  const navigate = useNavigate();
  const qc = useQueryClient();
  const toast = useToast();

  const job = useQuery({
    enabled: !!jobId,
    queryKey: ["job", jobId],
    queryFn: async () => must(await api.GET("/jobs/{id}", { params: { path: { id: jobId } } })),
  });
  const snap = snapshotOf(job.data);
  const item = snap && rows(snap).find((r) => r.kind === kind && r.item.remote_id === remoteId)?.item;
  const suggested = item?.suggested;
  const card =
    Number(search.get("card")) || (suggested?.action === "bind" ? suggested.card_id : item?.candidates?.[0]?.card_id) || 0;

  const [action, setAction] = useState<Option["action"]>();
  const act = action ?? (!item || suggested?.action === "bind" ? "bind" : (suggested?.action ?? "import"));
  const [choices, setChoices] = useState<Choices>({});
  const nested = kind === "items" ? (item?.lorebooks ?? []) : [];
  const [nestedPicks, setNestedPicks] = useState<Record<string, string>>({});
  const [nestedChoices, setNestedChoices] = useState<Record<string, Choices>>({});
  const nestedPick = (lb: Item) => {
    const key = nestedPicks[lb.remote_id] ?? (lb.suggested && optionKey(lb.suggested));
    return (lb.options ?? []).find((o) => optionKey(o) === key);
  };

  const cmp = useQuery({
    enabled: card > 0,
    queryKey: ["compare", instance, kind, remoteId, card],
    gcTime: 0,
    queryFn: () => compareItem(instance, kind, remoteId, card),
  });
  const nestedCmps = useQueries({
    queries: nested.map((lb) => {
      const o = nestedPick(lb);
      return {
        enabled: o?.action === "bind",
        queryKey: ["compare", instance, "lorebook-items", lb.remote_id, o?.card_id ?? 0],
        gcTime: 0,
        queryFn: () => compareItem(instance, "lorebook-items", lb.remote_id, o?.card_id ?? 0),
      };
    }),
  });

  const pickCard = (id: number) => {
    setSearch(
      (s) => {
        s.set("card", String(id));
        return s;
      },
      { replace: true },
    );
    setChoices({});
  };

  const resolve = useMutation({
    mutationFn: async () => {
      const body = resolution(remoteId, item?.app_hash ?? cmp.data?.app_hash ?? "", act, cmp.data, choices);
      const books = nested.flatMap((lb, i) => {
        const o = nestedPick(lb);
        return o ? [resolution(lb.remote_id, lb.app_hash, o.action, nestedCmps[i]?.data, nestedChoices[lb.remote_id])] : [];
      });
      if (books.length && act !== "skip") body.lorebooks = books;
      return resolveItem(instance, kind, remoteId, body);
    },
    onSuccess: () => {
      void qc.invalidateQueries({ queryKey: ["search"] });
      toast({ text: `Resolved ${item?.name || remoteId}. Push to send the library's side to the app.` });
      if (jobId) navigate(`/sync/reconciles/${jobId}`);
      else navigate(-1);
    },
    onError: (e) => {
      if (e instanceof ApiError && e.status === 409) {
        // Hunk IDs may differ in the fresh comparison, so the old choices can't carry over.
        setChoices({});
        setNestedChoices({});
        void qc.invalidateQueries({ queryKey: ["compare", instance] });
      }
      toast({ text: e.message, error: true });
    },
  });

  const ready =
    (act !== "bind" || !!cmp.data) &&
    (!!item || !!cmp.data) &&
    nested.every((lb, i) => nestedPick(lb)?.action !== "bind" || !!nestedCmps[i]?.data);
  const name = item?.name || remoteId;

  if (jobId && job.isPending) return <p className="page">Loading…</p>;
  if (job.isError) return <p className="error page">{job.error.message}</p>;
  return (
    <div className="review">
      <p>{jobId ? <Link to={`/sync/reconciles/${jobId}`}>← Reconcile #{jobId}</Link> : <Link to="/sync">← Sync</Link>}</p>
      <section aria-label={name}>
        <div className="row">
          <h1>{name}</h1>
          {item && <span className="muted">{item.verdict}</span>}
          <span className="row" role="radiogroup" aria-label="Action">
            {(["bind", "import", "skip"] as const).map((a) => (
              <label key={a} className="check">
                <input type="radio" name="action" checked={act === a} onChange={() => setAction(a)} />{" "}
                {a === "bind" ? "Bind" : a === "import" ? "Import as new" : "Skip"}
              </label>
            ))}
          </span>
          <button className="button primary" disabled={!ready || resolve.isPending} onClick={() => resolve.mutate()}>
            Resolve
          </button>
        </div>
        {suggested && (
          <p className="muted">
            Suggested: {optionLabel(suggested, item?.candidates)}
            {suggested.why && ` (${suggested.why})`}
          </p>
        )}
        <p className="muted">Resolving changes the library and the binding, not the app. Push afterwards.</p>
        <div className="row">
          {!!item?.candidates?.length && (
            <select className="input" aria-label="Library match" value={card} onChange={(e) => pickCard(Number(e.target.value))}>
              {!item.candidates.some((c) => c.card_id === card) && card > 0 && <option value={card}>#{card}</option>}
              {item.candidates.map((c) => (
                <option key={c.card_id} value={c.card_id}>
                  {c.name}
                  {c.bound_to ? ` (bound to ${c.bound_to})` : ""}
                </option>
              ))}
            </select>
          )}
          <OtherMatch kind={kind} onPick={pickCard} />
        </div>
        {card === 0 ? (
          <p>No library match. Find one above, or import it.</p>
        ) : cmp.isError ? (
          <p className="error">{cmp.error.message}</p>
        ) : !cmp.data ? (
          <p>Comparing…</p>
        ) : (
          act === "bind" && <Diff scope={remoteId} cmp={cmp.data} choices={choices} onChoose={(id, c) => setChoices({ ...choices, [id]: c })} />
        )}
      </section>
      {act !== "skip" &&
        nested.map((lb, i) => {
          const o = nestedPick(lb);
          const q = nestedCmps[i];
          const own = nestedChoices[lb.remote_id] ?? {};
          return (
            <section key={lb.remote_id} className="nested-item" aria-label={`World book ${lb.name || lb.remote_id}`}>
              <h2>
                {lb.name || lb.remote_id} <span className="muted">{lb.verdict}</span>
              </h2>
              {lb.error && <p className="error">{lb.error}</p>}
              {!!lb.options?.length && (
                <select
                  className="input"
                  aria-label={`Action for ${lb.name || lb.remote_id}`}
                  value={o ? optionKey(o) : ""}
                  onChange={(e) => {
                    setNestedPicks({ ...nestedPicks, [lb.remote_id]: e.target.value });
                    setNestedChoices({ ...nestedChoices, [lb.remote_id]: {} });
                  }}
                >
                  {lb.options.map((opt) => (
                    <option key={optionKey(opt)} value={optionKey(opt)}>
                      {optionLabel(opt, lb.candidates)}
                    </option>
                  ))}
                </select>
              )}
              {o?.action === "bind" &&
                (q?.data ? (
                  <Diff
                    scope={lb.remote_id}
                    cmp={q.data}
                    choices={own}
                    onChoose={(id, c) => setNestedChoices({ ...nestedChoices, [lb.remote_id]: { ...own, [id]: c } })}
                  />
                ) : q?.isError ? (
                  <p className="error">{q.error.message}</p>
                ) : (
                  <p>Comparing…</p>
                ))}
            </section>
          );
        })}
    </div>
  );
}
```
