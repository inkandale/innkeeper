# Web UI Card Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open a card from the grid, edit and save its fields, organize it, replace or crop its image, and browse, compare, and restore its revisions.

**Architecture:** Two API additions: the card response lists the collections a card is in, and `GET /{cards,lorebooks}/{id}/revisions/{revision_id}/compare/{other_id}` diffs two revisions with `internal/merge`. The UI adds `/cards/:id`, a left panel and a right frame of field sections, and `/cards/:id/history`. Unsaved edits are a draft held in React state on top of the revision they started from.

**Tech Stack:** Go 1.27, Huma v2, PostgreSQL, React, React Router, TanStack Query, `openapi-fetch`, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-05-web-ui-design.md`, "Card page" and "API additions". Build order phase 4.

## As built

The code differs from the tasks below in these ways:

- `PUT /cards/{id}` and `POST /cards/{id}/restore` require `source` in the generated schema, so the save, image, and restore calls send `source: "ui"`.
- The crop overlay is `CropDialog.tsx`: `Crop.tsx` and `crop.ts` are the same file on a case-insensitive filesystem.
- `clashes` lists a field only when the latest revision changed it too: `!same(latest[k], d.base[k]) && !same(latest[k], d.data[k])`. Task 3's `rebase` test gives `latest` a `list` key.
- A successful save moves edits typed while it was in flight onto the new head instead of dropping them, and clears the stale banner. `edit` and `use` update the draft with functional `setDraft`.
- Save stays disabled while the stale banner shows. Each "Use latest" button is labelled with its field.
- Tag and collection changes stay pending until the card refetches, so a quick second change can't overwrite the first. An unknown sync state gets the `unknown` badge.

## Design notes

- **A draft is three things:** the revision ID it started from, that revision's data, and the edited data. A field is unsaved when its edited value differs from the base value. Save sends `base_revision_id` and the whole edited data object, so fields the page doesn't show, such as `tags` and `character_book`, pass through unchanged.
- **A `409` rebases field by field.** "Compare with the latest" reloads the head and lists only the fields both you and the other writer changed, with Latest and Yours side by side. "Keep my version" moves the draft onto the new head, keeping your changed fields and taking every other field from the head. Nothing is lost silently, and no client diff library is needed.
- **The revision compare reuses `merge.Compare`** with no ancestor. In each hunk, `library` is the first revision's value and `app` the second's. The history view renders `library` as removed text and `app` as added text.
- **History's two modes.** Against the previous revision, it shows what the chosen revision changed. Against the head, it shows what changed since. Revisions list newest first, so the head is the first one.
- **Image changes save at once.** Replace and Crop write a revision with the head's data and the new avatar. An open draft based on that head moves onto the new revision, so the next Save doesn't hit a `409`.
- **Crop runs in the browser.** A fixed 200×300 box shows the image with CSS `transform`. Drag pans, a range input zooms, and `fit()` keeps the box covered. Save draws the shown area of the full-size image to a canvas at native resolution and uploads the PNG as a new blob, so the original stays in history.
- **Native controls.** Field sections are `<details>`, textareas grow with CSS `field-sizing: content`, and the crop box is a plain overlay. There is no dialog library.
- **Leaving asks first.** `useBlocker` catches in-app navigation to another path, and `beforeunload` catches reloads and closing the tab. The page is keyed by card ID, so moving to another card starts with a clean draft.
- **Out of this phase:**
  - Delete. The API has no card delete, so the page offers Archive only.
  - The push preview and the drift review link (phase 7). Push starts a job as the selection bar does, and sync shows each target's state.
  - Catalog sources' read-only mode and "Adopt into library" (the archive catalog's spec).
  - Playwright. No phase has added it yet, and Vitest covers the save and `409` flows.

export type Data = Record<string, unknown>;

/** Draft is unsaved edits on top of the revision they started from. */
export type Draft = { baseId: number; base: Data; data: Data };

const same = (a: unknown, b: unknown) => JSON.stringify(a) === JSON.stringify(b);

/** changed lists the fields whose edited value differs from the base revision's. */
export function changed(d: Draft | null): Set<string> {
  const out = new Set<string>();
  if (!d) return out;
  for (const k of new Set([...Object.keys(d.base), ...Object.keys(d.data)])) if (!same(d.base[k], d.data[k])) out.add(k);
  return out;
}

/** rebase moves a draft onto a newer revision, keeping only the fields the draft changed. */
export function rebase(d: Draft, baseId: number, base: Data): Draft {
  const data = { ...base };
  for (const k of changed(d)) {
    if (k in d.data) data[k] = d.data[k];
    else delete data[k];
  }
  return { baseId, base, data };
}

/** clashes lists the fields the draft changed that differ in latest too. */
export function clashes(d: Draft, latest: Data): string[] {
  return [...changed(d)].filter((k) => !same(latest[k], d.data[k])).sort();
}

/** tokens estimates a text's token count. The UI labels it with "~". */
export const tokens = (s: string) => Math.ceil(s.length / 4);

/** text returns v if it's a string, or "". */
export const text = (v: unknown) => (typeof v === "string" ? v : "");

/** show prints a field value for reading. */
export const show = (v: unknown) => (v === undefined ? "" : typeof v === "string" ? v : JSON.stringify(v, null, 2));
```

/** upload stores a file as a blob and returns its sha256. */
export async function upload(file: Blob): Promise<string> {
  const res = await api.POST("/blobs", {
    // The schema types a binary body as string; send the bytes as they are.
    body: file as unknown as string,
    bodySerializer: (b) => b,
    headers: { "Content-Type": "application/octet-stream" },
  });
  return must(res).sha256;
}

export type Size = { w: number; h: number };
/** View is a zoom (1 = the image just covers the box) and the image center's offset from the box center, in screen pixels. */
export type View = { zoom: number; dx: number; dy: number };
export type Rect = { x: number; y: number; w: number; h: number };

/** scale is how many screen pixels one image pixel takes at a zoom. */
export const scale = (img: Size, box: Size, zoom: number) => Math.max(box.w / img.w, box.h / img.h) * zoom;

/** fit clamps a view so the image covers the box, and returns the image area the box shows. */
export function fit(img: Size, box: Size, v: View): { view: View; rect: Rect } {
  const zoom = Math.max(1, v.zoom);
  const s = scale(img, box, zoom);
  const maxX = (img.w * s - box.w) / 2;
  const maxY = (img.h * s - box.h) / 2;
  const dx = Math.min(maxX, Math.max(-maxX, v.dx));
  const dy = Math.min(maxY, Math.max(-maxY, v.dy));
  return {
    view: { zoom, dx, dy },
    rect: { x: img.w / 2 - (box.w / 2 + dx) / s, y: img.h / 2 - (box.h / 2 + dy) / s, w: box.w / s, h: box.h / s },
  };
}
```

import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { useEffect, useState } from "react";
import { useBlocker, useParams } from "react-router";
import { api, must } from "../api/client";
import type { components } from "../api/schema";
import { useToast } from "../shell/Toasts";
import { changed, type Data, type Draft } from "./draft";
import { Fields } from "./Fields";
import { Panel } from "./Panel";
import "./Card.css";

export type Entity = components["schemas"]["EntityOut"];

/** Card is the card page. It's keyed by ID so another card starts with no draft. */
export function Card() {
  const { id } = useParams();
  return <Editor key={id} id={Number(id)} />;
}

function Editor({ id }: { id: number }) {
  const qc = useQueryClient();
  const toast = useToast();
  const card = useQuery({
    queryKey: ["card", id],
    queryFn: async () => must(await api.GET("/cards/{id}", { params: { path: { id } } })),
  });
  const [draft, setDraft] = useState<Draft | null>(null);
  const dirty = changed(draft);
  useLeaveGuard(dirty.size > 0);

  const save = useMutation({
    mutationFn: async (d: Draft) =>
      must(await api.PUT("/cards/{id}", { params: { path: { id } }, body: { base_revision_id: d.baseId, data: d.data } })),
    onSuccess: (e) => {
      qc.setQueryData(["card", id], e);
      void qc.invalidateQueries({ queryKey: ["card", id, "revisions"] });
      setDraft(null);
      toast({ text: "Saved" });
    },
    onError: (e) => toast({ text: e.message, error: true }),
  });

  if (card.isPending) return null;
  if (card.isError) return <p className="error page">{card.error.message}</p>;
  const head = card.data;
  const headData = (head.revision.data ?? {}) as Data;
  const data = draft?.data ?? headData;
  const edit = (key: string, value: unknown) => {
    const d = draft ?? { baseId: head.revision.id, base: headData, data: headData };
    setDraft({ ...d, data: { ...d.data, [key]: value } });
  };

  return (
    <div className="card-page">
      <Panel card={head} data={data} edit={edit} dirty={dirty.size > 0} saving={save.isPending} onSave={() => draft && save.mutate(draft)} />
      <div className="card-main">
        <Fields data={data} dirty={dirty} edit={edit} />
      </div>
    </div>
  );
}

// useLeaveGuard asks before leaving the page while on is true: in the app
// through the router, and on reload or close through the browser.
function useLeaveGuard(on: boolean) {
  const blocker = useBlocker(({ currentLocation, nextLocation }) => on && currentLocation.pathname !== nextLocation.pathname);
  useEffect(() => {
    if (blocker.state !== "blocked") return;
    if (window.confirm("Leave without saving your edits?")) blocker.proceed();
    else blocker.reset();
  }, [blocker]);
  useEffect(() => {
    if (!on) return;
    const warn = (e: BeforeUnloadEvent) => e.preventDefault();
    window.addEventListener("beforeunload", warn);
    return () => window.removeEventListener("beforeunload", warn);
  }, [on]);
}

import { useState, type PointerEvent } from "react";
import { fit, scale, type Size, type View } from "./crop";

const box: Size = { w: 200, h: 300 };

/** Crop picks a 2:3 area of an image by dragging and zooming, and hands back a PNG of it at full resolution. */
export function Crop({ src, onDone, onCancel }: { src: string; onDone: (png: Blob) => void; onCancel: () => void }) {
  const [img, setImg] = useState<HTMLImageElement | null>(null);
  const [view, setView] = useState<View>({ zoom: 1, dx: 0, dy: 0 });
  const [drag, setDrag] = useState<{ x: number; y: number } | null>(null);
  const size = img ? { w: img.naturalWidth, h: img.naturalHeight } : null;
  const set = (v: View) => size && setView(fit(size, box, v).view);
  const s = size ? scale(size, box, view.zoom) : 1;

  const move = (e: PointerEvent) => {
    if (!drag) return;
    set({ ...view, dx: view.dx + e.clientX - drag.x, dy: view.dy + e.clientY - drag.y });
    setDrag({ x: e.clientX, y: e.clientY });
  };
  const save = () => {
    if (!img || !size) return;
    const { rect } = fit(size, box, view);
    const canvas = document.createElement("canvas");
    canvas.width = Math.round(rect.w);
    canvas.height = Math.round(rect.h);
    canvas.getContext("2d")?.drawImage(img, rect.x, rect.y, rect.w, rect.h, 0, 0, canvas.width, canvas.height);
    canvas.toBlob((b) => b && onDone(b), "image/png");
  };

  return (
    <div className="crop-backdrop">
      <div className="crop" role="dialog" aria-modal="true" aria-label="Crop image">
        <div
          className="crop-box"
          style={{ width: box.w, height: box.h }}
          onPointerDown={(e) => {
            e.currentTarget.setPointerCapture(e.pointerId);
            setDrag({ x: e.clientX, y: e.clientY });
          }}
          onPointerMove={move}
          onPointerUp={() => setDrag(null)}
        >
          <img
            src={src}
            alt=""
            draggable={false}
            onLoad={(e) => setImg(e.currentTarget)}
            style={
              size
                ? { width: size.w * s, height: size.h * s, transform: `translate(calc(-50% + ${view.dx}px), calc(-50% + ${view.dy}px))` }
                : undefined
            }
          />
        </div>
        <label>
          Zoom{" "}
          <input type="range" min={1} max={4} step={0.05} value={view.zoom} onChange={(e) => set({ ...view, zoom: Number(e.target.value) })} />
        </label>
        <div className="row">
          <button className="button primary" disabled={!img} onClick={save}>
            Save crop
          </button>
          <button className="button" onClick={onCancel}>
            Cancel
          </button>
        </div>
      </div>
    </div>
  );
}

/** Hunks renders a field's hunks inline: the first revision's text struck out, the second's marked. */
export function Hunks({ field }: { field: Field }) {
  return (
    <p className="hunks">
      {(field.hunks ?? []).map((h) =>
        h.status === "same" ? (
          <span key={h.id}>{show(h.library)}</span>
        ) : (
          <span key={h.id}>
            {h.library !== undefined && <del>{show(h.library)}</del>}
            {h.app !== undefined && <ins>{show(h.app)}</ins>}
          </span>
        ),
      )}
    </p>
  );
}

/** History lists a card's revisions and diffs the chosen one against the one before it or the head. */
export function History() {
  const id = Number(useParams().id);
  const [params, setParams] = useSearchParams();
  const qc = useQueryClient();
  const toast = useToast();
  const revs = useQuery({
    queryKey: ["card", id, "revisions"],
    queryFn: async () => must(await api.GET("/cards/{id}/revisions", { params: { path: { id } } })),
  });
  const list = revs.data ?? [];
  // Revisions list newest first, so the head is first.
  const head = list[0];
  const at = Math.max(0, list.findIndex((r) => r.id === Number(params.get("rev"))));
  const rev = list[at];
  const vsHead = params.get("against") === "head";
  const [from, to] = vsHead ? [rev, head] : [list[at + 1], rev];

  const diff = useQuery({
    queryKey: ["card", id, "compare", from?.id, to?.id],
    enabled: !!from && !!to && from.id !== to.id,
    queryFn: async () =>
      must(
        await api.GET("/cards/{id}/revisions/{revision_id}/compare/{other_id}", {
          params: { path: { id, revision_id: from!.id, other_id: to!.id } },
        }),
      ),
  });
  const restore = useMutation({
    mutationFn: async (r: { id: number; base: number }) =>
      must(await api.POST("/cards/{id}/restore", { params: { path: { id } }, body: { revision_id: r.id, base_revision_id: r.base } })),
    onSuccess: (_, r) => {
      void qc.invalidateQueries({ queryKey: ["card", id] });
      setParams({});
      toast({ text: `Restored revision ${r.id}` });
    },
    onError: (e) => toast({ text: e.message, error: true }),
  });

  const set = (next: Record<string, string>) => setParams({ ...Object.fromEntries(params), ...next });
  const changes = (diff.data?.fields ?? []).filter((f) => (f.hunks ?? []).some((h) => h.status !== "same"));

  if (revs.isError) return <p className="error page">{revs.error.message}</p>;
  return (
    <div className="history">
      <nav className="card-aside" aria-label="Revisions">
        <Link to={`/cards/${id}`}>← Back to card</Link>
        <ol className="plain">
          {list.map((r) => (
            <li key={r.id}>
              <button className="revision" aria-current={r.id === rev?.id ? "true" : undefined} onClick={() => set({ rev: String(r.id) })}>
                <strong>{r.message || `Revision ${r.id}`}</strong>
                <span className="muted">
                  {new Date(r.created_at).toLocaleString()} · {r.source}
                </span>
              </button>
            </li>
          ))}
        </ol>
      </nav>
      <div className="card-main">
        {rev && (
          <>
            <div className="row">
              <h1>{rev.message || `Revision ${rev.id}`}</h1>
              <label className="check">
                <input type="radio" name="against" checked={!vsHead} onChange={() => set({ against: "prev" })} /> Against previous
              </label>
              <label className="check">
                <input type="radio" name="against" checked={vsHead} onChange={() => set({ against: "head" })} /> Against head
              </label>
              {head && rev.id !== head.id && (
                <button className="button primary" disabled={restore.isPending} onClick={() => restore.mutate({ id: rev.id, base: head.id })}>
                  Restore
                </button>
              )}
            </div>
            {!from ? (
              <p>This is the first revision.</p>
            ) : from.id === to?.id ? (
              <p>This is the head.</p>
            ) : diff.isError ? (
              <p className="error">{diff.error.message}</p>
            ) : diff.isPending ? (
              <p>Loading…</p>
            ) : (
              <>
                {from.avatar !== to?.avatar && (
                  <section>
                    <h2>Image</h2>
                    <p className="row">
                      {from.avatar ? <img className="history-thumb" src={thumb(from.avatar, 160)} alt="Before" /> : "None"} →{" "}
                      {to?.avatar ? <img className="history-thumb" src={thumb(to.avatar, 160)} alt="After" /> : "None"}
                    </p>
                  </section>
                )}
                {changes.length === 0 && <p>No field changed.</p>}
                {changes.map((f) => (
                  <section key={f.path}>
                    <h2>{f.path}</h2>
                    <Hunks field={f} />
                  </section>
                ))}
              </>
            )}
          </>
        )}
      </div>
    </div>
  );
}
