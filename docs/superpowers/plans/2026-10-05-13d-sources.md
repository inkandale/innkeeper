# Sources Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cards and lorebooks record the sites they were published on, detected from their data or added by the owner, so reconcile can match on them.

**Architecture:** Two tables in the library, a detector list in `internal/library`, detection called from the shared import path and from bind, and small API, CLI, and MCP surfaces. Nothing here uses a source's content; that waits for the archive catalog's `catalog.get`.

**Tech Stack:** Go, pgx, huma. No new dependencies.

**Spec:** `2026-10-05-reconcile-design.md`, Sources.

**Kaneo:** INN-26, part of INN-22.

## Design notes

- **Schema** (`internal/db/migrations/0009_sources.sql`):
  ```sql
  CREATE TABLE card_source (
      id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
      card_id bigint NOT NULL REFERENCES card,
      kind text NOT NULL CHECK (kind ~ '^[a-z][a-z0-9-]*$'),
      ref text NOT NULL CHECK (ref <> ''),
      external_id text,
      url text,
      linked_by text NOT NULL CHECK (linked_by IN ('auto', 'owner')),
      -- Set when the owner removes it, so detection doesn't add it back.
      removed_at timestamptz,
      created_at timestamptz NOT NULL DEFAULT now(),
      UNIQUE (card_id, kind, ref)
  );
  CREATE INDEX ON card_source (kind, ref) WHERE removed_at IS NULL;
  ```
  `lorebook_source` is the same with `lorebook_id`.
- **Library API** (`internal/library/sources.go`), for both entity kinds through the existing `Entities` kind table:
  ```go
  type Source struct {
  	ID         int64     `json:"id"`
  	Kind       string    `json:"kind"`
  	Ref        string    `json:"ref"`
  	ExternalID string    `json:"external_id,omitempty"`
  	URL        string    `json:"url,omitempty"`
  	LinkedBy   string    `json:"linked_by"`
  	CreatedAt  time.Time `json:"created_at"`
  }
  func (s *Entities) Sources(ctx, id) ([]Source, error)            // excludes removed
  func (s *Entities) AddSource(ctx, id, src Source) (Source, error) // owner; un-removes a removed row
  func (s *Entities) RemoveSource(ctx, id, sourceID int64) error    // sets removed_at
  func (s *Entities) DetectSources(ctx, id, data json.RawMessage) error // auto, idempotent; skips removed rows
  func (s *Entities) BySource(ctx, kind, ref string) ([]int64, error)
  ```
- **Detectors** (`internal/library/detect.go`):
  ```go
  type detector struct {
  	kind     string
  	fromData func(data map[string]any, lorebook bool) (Source, bool) // reads extensions
  	fromURL  func(u *url.URL) (Source, bool)
  	fromRef  func(ref string, lorebook bool) (Source, bool)
  }
  var detectors = []detector{chub}
  func Detect(data json.RawMessage, lorebook bool) []Source
  func ParseSourceURL(raw string) (Source, error) // ErrInvalid when no detector accepts it
  // ValidateSource checks kind and ref with the detector's fromRef and returns the canonical source.
  func ValidateSource(src Source, lorebook bool) (Source, error)
  ```
  `chub`: from `extensions.chub` with a non-empty `full_path` → `ref: full_path`, `external_id: id` as a string, `url: https://chub.ai/characters/<full_path>`. From a URL on `chub.ai` or `www.chub.ai` with path `/characters/<a>/<b>` → `ref: <a>/<b>`. A lorebook's `extensions.chub` works the same with `/lorebooks/`.
- **Where detection runs.** `library.ImportCard` (used by the folder importer and target import), lorebook import, and `targets` bind, as one more idempotent step after the write, as `ImportCard` already orders its steps so a retry finishes them. Reconcile calls `Detect` without writing.
